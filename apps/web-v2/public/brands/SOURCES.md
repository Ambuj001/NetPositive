# Brand logos

All logos are trademarks of their owners. NetPositive shows them only to identify the brand of a gift voucher. It does not claim any partnership or endorsement.

| File | Source |
| --- | --- |
| amazon.svg | Wikimedia Commons, `File:Amazon icon.svg` |
| kalyan.svg | Wikimedia Commons, `File:Kalyan Jewellers logo.svg`, cropped to the emblem |
| ajio.png, bigbasket.png, flipkart.png, tatacliq.png | The brand's official Google Play app icon |
| everything else | The brand's own site icon (favicon / app icon), resized to 256 px |

To add a brand, put a square image here named `<brand id>.png` or `.svg` and set `logo` on its entry in `src/lib/data.ts`. If the file fails to load, `BrandMark` falls back to the coloured letter tile.
