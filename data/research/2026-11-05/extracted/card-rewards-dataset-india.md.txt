Prepared 5 Nov 2026 for the Voucher Rail agent. Purpose: the numbers the agent shows a
buyer when it picks the card and route for a voucher. Every row carries a source grade; the
agent must re-check the official page before displaying a number to a user.
Source grades
- OFFICIAL — bank MITC / terms PDF / product page read directly.
- SECONDARY — card-review site dated Oct–Nov 2026 citing bank terms. Use for the
build; confirm on the official page before going live.
- PENDING — not found yet.
How % is computed: points per spend unit ÷ spend unit × best official
point value. Example: Infinia 5 RP per ₹150 × ₹1 = 3.33%. "Cashback" cards are already in
%.
1. MCC reference (what the agent matches against)
MCCs are set by the network and acquirer; banks state many as "best effort". A voucher bought
on a bank portal is coded by the portal's merchant, not the brand, so the agent records the MCC
seen on the user's statement after the first purchase.

6. Agent rules
1. Rank only (card × official channel) pairs the user holds; never suggest an excluded MCC
route.
2. Subtract each card's remaining monthly/cycle cap before showing %; reserve the cap
while an order is open.
3. Apply per-transaction rounding (floor of spend ÷ unit).
4. Show "expected" until points post (SmartBuy: up to 90 working days).
5. Show source link + "checked on" date next to every number; block the number if the
source is older than 30 days.
6. For wallet routes, add the bank fee and zero reward before ranking.

DCB/Regalia Gold voucher multipliers, Amazon Pay ICICI gift-card treatment).
